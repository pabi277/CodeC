CodeC — a C programming IDE for your Android phone.

Write C in projects or as single files and tap RUN — the built-in TCC compiler works offline and instantly, with no Termux and no setup. Or open a real VT/ANSI terminal, type cc hello.c -o a.out and run ./a.out, and install from a hub of 25+ signed packages — git, python, clang and more. HTML projects even get an in-app web preview with live reload.

What’s inside

Built-in compiler

A static musl TCC toolchain ships inside the APK. Compiling works offline and instantly — no downloads, no Termux, no setup — on arm64-v8a phones and x86_64 emulators.

How the four engines work

Real terminal

A genuine VT/ANSI terminal (PTY) — a mini Termux in your pocket. Type cc hello.c -o a.out, then ./a.out; input programs (scanf) run here too.

Your first compile

Package hub

25+ signed packages from CodeC’s own repository: git, python, clang, nano, make, ripgrep, tmux and more — 1-tap install, live status badges.

Browse the package hub

Spck-grade editor

A projects hub with file tree, tabs with dirty state, autosave, find & replace, error squiggles — and honest git: staged commits, conflict flow, pushes that never fake success.

See the full tour

Web preview

Preview HTML projects in-app, served over a local loopback server — relative CSS/JS, fetch, ES modules and live reload on save, with console output under the page.

Try it in the first hour

Always updatable

Update without leaving the app: Settings → Install APK from GitHub downloads the latest release APK and opens the installer. New builds come straight from CI.

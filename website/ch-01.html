What you will learn

  • Find the signed release and understand the first screen.
  • Recognize the five tabs and verify a saved file.

Before you begin

A supported Android device and a connection for the APK download. No Linux userland or AI key needed.

Get the right download

Open GitHub Releases from Install, choose the CodeC IDE app-v release and download the universal APK—not the source ZIP or a userland bootstrap. Android may require Install unknown apps for the browser or file manager that opens it. Allow that trusted installation source deliberately, install, then turn the permission off if no longer needed.

The documented release is v1.3.18 / versionCode 22. If replacing a differently signed debug build, export your source projects outside the app before uninstalling. A fresh install removes private data.

The first screen is an invitation

Read the three-step introduction or skip its educational pages. The privacy acknowledgement still needs acceptance before normal entry; it grants no Android permission and sends no network request. CodeC seeds an editable offline Arcade project once and opens index.html. Tap RUN to preview Snake, Block Party or Tic-Tac-Toe, or start your own project instead.

Your edits are not overwritten and a deleted starter stays deleted. Returning launches resume the last file. Replay the introduction from Settings → About.

Make a note you can return to

  1. Choose Projects → + → New Project. Name it CourseNotes and use Auto (detect), which starts empty.
  2. In the Editor file drawer, choose New file and create note.txt. Type the line below.
  3. Pause about two seconds for autosave. Switch tabs, return and reopen note.txt. You should see the same line.

note.txt

hello codec

An opened single file and a whole project are different contexts. Use the project card’s ⋮ → Open in editor to work with the whole file drawer. Do not tap RUN on a note expecting a program.

Optional: look at your environment

If you want shell exercises now, choose Terminal’s optional Linux setup and wait for it to finish. The download needs internet; the other tabs stay available. Run:

Inspect your shell

pwd
printf 'HOME=%s\nPREFIX=%s\n' "$HOME" "$PREFIX"

Expected: a current directory and two environment paths. HOME and PREFIX are different concepts: your shell home versus installed tools. In CodeC, PREFIX is under the app’s files/usr; the terminal may be in a project after a file handoff. Do not treat a different prompt color as an error.

Try it yourself

  1. Change note.txt to “hello again”, reopen it and verify the new text.
  2. Find one package badge without installing it. Expected: you can distinguish availability from installation.
  3. Open Arcade’s index.html and RUN it. Expected: a local web preview, not a compiler log.

Common mistakes

  • Do not reinstall repeatedly before reading the error. Backup comes before uninstall.
  • No Linux download is required just to open a static HTML preview.
  • A text file is not a runnable source file.

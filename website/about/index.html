The mark and the idea

The original >_ mark stands for a place to write and run. CodeC brings an editor, built-in C compiler, terminal, projects and a local web preview together. No app screenshot is invented here: the Home example is text, not a simulated device.

This guide describes the shipped app through Phases 1–96 and app-v1.3.18, not every historical proposal. The old Open Folder and engine-picker interfaces are not current features.

An editor made for the phone

File-type icons, tabs, a file drawer, autosave, find/replace, formatting and diagnostics keep ordinary editing close at hand. TextMate grammars supply VS Code Dark+ colors; other editor themes are available in Settings. Snippet packs and built-in Emmet reduce typing. TAB accepts a suggestion; Enter stays a newline. Your phone keyboard is the default, with optional CodeC Keys.

Explore the editor without assuming every tool in a desktop IDE is present.

More than an editor

  • Offline TCC on supported ABIs; optional Clang and automatic Termux fallback.
  • Real VT/ANSI terminal with multiple sessions and opt-in Linux tools.
  • Signed CodeC package metadata, not official Termux package mixing.
  • Whole-project HTML preview, relative resources, console and opt-in LAN URLs/QR.
  • Git readiness checks, local-versus-pushed truth and source-only backup/export.
  • Optional BYOK AI: explanations and reviewed proposals, never autonomous writes/runs.

Respect the work, and name the limits

CodeC-generated run artifacts are temporary; explicitly named output stays where you ask for it. Git hygiene uses repo-local exclusions and respects your .gitignore. The updater checks version and checksum. Source-project backups exclude the Linux environment, settings and credentials. A third-launch safe-mode path helps recover from a crash loop.

Git repository publication defaults private where offered; the reliable first-remote route is to create the repository on GitHub and add its URL. A failed push is never presented as uploaded work.

Small APK, real trade-offs

The published v1.3.18 universal APK is 7,217,532 bytes, versionCode 22. R8/shrinking is part of the release history; the historical “74% smaller” comparison belongs to v1.3.17, not this APK. The minimum is Android 7/API 24; older install tiers and 32-bit compatibility need care. targetSdk28 is deliberate for downloaded-tool execution compatibility, not a claim that Android restrictions disappear.

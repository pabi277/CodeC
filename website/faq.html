B-1: a huge folder or import stalls

Large trees are expensive to scan. Import a smaller source-only ZIP, excluding caches and dependencies where practical. If the tree stalls for 30 seconds or more, force-stop and reopen. Do not use the removed Open Folder feature; use New Project, Clone or Import ZIP.

B-2: an older 32-bit tablet will not start

The universal APK includes native ABI lanes, but beta notes record install/boot failures on some older tablets. Report model, Android version, ABI and exact symptom. Do not promise that the arm64 toolchain can run on a 32-bit CPU.

B-3: a long command dies when the screen sleeps

Android battery restrictions may kill a job despite the foreground service/wake lock. Keep its notification and the app available; inspect battery restrictions. Terminal sessions or tmux do not make a process immortal.

B-4: Git credentials are missing after restore

Reconnect in Source Control → ⋮ → Git Credentials. Credentials do not ride the project backup. Never put a token in a URL, README, screenshot or issue; use the app’s credential form.

B-5: Android says the APK is invalid

A partial download can cause a parse error. Download the signed universal APK again and compare the release checksum. The updater checks SHA256. Export projects before switching signing keys or uninstalling.

B-6: a very long line looks wrong

Lines over roughly 10 KB can trigger the editor’s display guard. Split an unwieldy line into readable lines. The display substitute is not an edit to the file on disk.

B-7: the app closes at splash twice

On the third launch, use Try starting without my settings. Safe mode bypasses onboarding/sample seeding for recovery; source projects remain. Preserve a backup and inspect crash-log text before sharing a report.

B-8: no built-in compiler on 32-bit

Bundled TCC is arm64-v8a/x86_64 only. The arm64 Clang module is not a 32-bit fix. A compatible external fallback may help where supported, but device compatibility is not guaranteed.

Compiler could not start / Permission denied / Exec format error

Read the exact Output message. Permission denied may be Android W^X/noexec policy; Exec format error usually means an ABI mismatch. Keep projects in app-private storage, verify your device class, and use the automatic fallback guidance. There is no engine picker.

Runtime libraries missing, or a program appears frozen

Distinguish a compiler/runtime installation failure from your program’s error. Check the environment status and named missing tool. An interactive scanf program may simply await Terminal input; a loop may be infinite. Use Stop/Ctrl-C where available; do not invent universal timeout guarantees.

Did COMMIT & PUSH upload my work?

A local commit is not a remote push. Read the result’s remote/branch and the unpushed indicator. Committed locally — NOT pushed means your work is still on the phone. Fix connectivity/credentials/remote and retry PUSH; do not delete the local commits.

What does my backup include?

Export all projects creates a project backup ZIP. Save it outside app-private storage before uninstalling and restore with Import projects backup. Source projects are the backup scope, not the Linux prefix, app settings or tokens.

Why can another phone not open my preview?

The On this phone address is loopback: another device’s loopback points at itself. Enable LAN sharing deliberately, use Other devices/QR on the same Wi-Fi, keep the server alive and check network isolation. Share only non-sensitive project files.

Is AI free or unlimited?

No. It uses your provider key, terms, quota and bill. Gemini is the default; NVIDIA Build is a manual dev/test option. CodeC has no shared key, proxy or hosted model. App caps and provider rate limits both apply.

Why did my AI history disappear?

Raw chat and drawer titles are in memory under D6, up to 20 conversations per project. App death clears them. Bounded task memory and undo preimages are separate local stores, not a transcript archive.

Can CodeC read or send my files?

With ONE storage approval the app can read shared files. AI Send starts a disclosed task whose bounded read follow-ups may send admitted text; edits and runs require separate taps. Provider retention is not zero. Read the full Privacy page.

How do I update safely?

Settings → About → Check for updates is user-triggered, numeric-version guarded and checksum verified. Missing checksum opens Releases. Changing from debug to a differently signed release may need a fresh install: export first.

How do I report a problem?

Record app version, Android/ABI, exact steps, expected/actual result and relevant Output/log text. Inspect and redact secrets before sharing. Use GitHub Issues publicly; personal contact details stay inside the app.

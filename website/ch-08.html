1. The shape of a program

An include brings declarations into view. main is the entry point. A zero return reports success to the shell. All examples here use conservative ANSI-C style: declarations before statements, fixed-size arrays and no C11-only features. Save each as a separate file; each has its own main.

shape.c

#include <stdio.h>
int main(void) {
    puts("Start small");
    return 0;
}

Compile and run shape.c

cc shape.c -o example
./example

No input needed.

Expected output · shape.c

Start small

2. Values and types

An int stores a whole number, double a floating-point value and char one character. Single quotes are for a character; double quotes make a string. The format must match the value: %d, %f and %c are not interchangeable. Try changing the three initial values and predict the line.

types.c

#include <stdio.h>
int main(void) {
    int count = 3;
    double price = 2.5;
    char grade = 'A';
    printf("%d %.2f %c\n", count, price, grade);
    return 0;
}

Compile and run types.c

cc types.c -o example
./example

No input needed.

Expected output · types.c

3 2.50 A

3. Print a small card

%s prints a null-terminated string; %p prints an address using a void-pointer argument. sizeof includes the string terminator here, so Ada occupies four bytes. Addresses and many type sizes vary by device; do not compare a pointer with a fabricated fixed address. Exercise: add a %.1f score field.

card.c

#include <stdio.h>
int main(void) {
    char name[] = "Ada";
    int lessons = 8;
    printf("Name: %s\nLessons: %d\n", name, lessons);
    printf("String bytes: %lu\n", (unsigned long)sizeof name);
    printf("Address: %p\n", (void *)name);
    return 0;
}

Compile and run card.c

cc card.c -o example
./example

No input needed.

Expected output · card.c

Name: Ada
Lessons: 8
String bytes: 4
Address: <varies on each run>

4. Read bounded input

Run this in Terminal. scanf needs an address for a numeric destination, hence &year. An array name already points at its first element, so the string argument is name. %19s leaves one byte for the terminator in a 20-byte array. It reads one word, not a name containing spaces. Check the conversion count rather than use uninitialized values.

input.c

#include <stdio.h>
int main(void) {
    char name[20];
    int year;
    puts("Name and birth year?");
    if (scanf("%19s %d", name, &year) != 2) return 1;
    if (year < 1900 || year > 2030) return 1;
    printf("%s will turn %d in 2030\n", name, 2030 - year);
    return 0;
}

Compile and run input.c

cc input.c -o example
./example

Type Ada 2000 then Enter. The transcript shows program output, not your echoed input. Owner device gate: record this exercise.

Expected output · input.c

Name and birth year?
Ada will turn 30 in 2030

5. Integer and floating-point arithmetic

Integer division discards the fractional part; one double operand changes the calculation. % is remainder, == compares, = assigns, && means both conditions, || either and ! negates. Use small inputs while learning; overflowing signed integers is not a safe wrapping calculator. Try 8 in place of 5.

operators.c

#include <stdio.h>
int main(void) {
    int a = 5;
    printf("%d %.1f %d\n", a / 2, a / 2.0, a % 2);
    printf("%d\n", a > 0 && a < 10);
    return 0;
}

Compile and run operators.c

cc operators.c -o example
./example

No input needed.

Expected output · operators.c

1

6. Branches and loops

First select an action with if/else, then repeat with while or for. Keep counters initialized and update them so the loop terminates. Enter the following as three separate programs; compile the one you want, not all three main functions together.

parity.c

#include <stdio.h>
int main(void) {
    int n = 7;
    if (n % 2 == 0) puts("even");
    else puts("odd");
    return 0;
}

countdown.c

#include <stdio.h>
int main(void) {
    int n = 3;
    while (n > 0) {
        printf("%d\n", n);
        n--;
    }
    return 0;
}

sum.c

#include <stdio.h>
int main(void) {
    int i;
    int total = 0;
    for (i = 1; i <= 5; i++) total += i;
    printf("%d\n", total);
    return 0;
}

Run each program

./example

./example

7. Functions pass values

A function receives copies of integer arguments. Changing a and b does not change x and y in the caller. void says this function returns no value. The next pointer example will make the difference explicit. Exercise: predict both lines before running.

values.c

#include <stdio.h>
void swap(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
    printf("Inside: %d %d\n", a, b);
}
int main(void) {
    int x = 1, y = 2;
    swap(x, y);
    printf("Outside: %d %d\n", x, y);
    return 0;
}

Compile and run values.c

cc values.c -o example
./example

No input needed.

Expected output · values.c

Inside: 2 1
Outside: 1 2

8. Arrays and strings

Array indexes begin at zero. A C string ends at a zero byte; strlen does not count that terminator. This strcpy is safe only because the known literal fits the destination. Do not copy arbitrary input into a fixed buffer without a bound. Exercise: reverse a different short literal that fits in 16 bytes including its terminator.

reverse.c

#include <stdio.h>
#include <string.h>
int main(void) {
    char word[16];
    int i, length;
    strcpy(word, "codec");
    length = (int)strlen(word);
    for (i = length - 1; i >= 0; i--) putchar(word[i]);
    putchar('\n');
    return 0;
}

Compile and run reverse.c

cc reverse.c -o example
./example

No input needed.

9. A pointer stores an address

&x obtains an address; *p reads or writes the value at that address. Passing &x lets swap change the caller’s x. Keep pointers tied to live objects; an uninitialized or expired pointer is not a useful address. Owner device gate: run this and record the changed caller values.

pointers.c

#include <stdio.h>
void swap(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}
int main(void) {
    int x = 1, y = 2;
    int *p = &x;
    printf("Before: %d %d; *p=%d\n", x, y, *p);
    swap(&x, &y);
    printf("After: %d %d; *p=%d\n", x, y, *p);
    return 0;
}

Compile and run pointers.c

cc pointers.c -o example
./example

No input needed.

10. Capstone: temperature converter

Functions isolate the formulas; the menu loop decides which to use. scanf uses %lf for a double destination, while printf uses %f for its double value. Bad input ends the example with a nonzero status instead of reusing an undefined value. Run interactively in Terminal.

converter.c

#include <stdio.h>
double to_f(double c) { return c * 9.0 / 5.0 + 32.0; }
double to_c(double f) { return (f - 32.0) * 5.0 / 9.0; }
int main(void) {
    int choice;
    double value;
    while (1) {
        puts("1 C->F, 2 F->C, 0 quit");
        if (scanf("%d", &choice) != 1) return 1;
        if (choice == 0) break;
        if (choice != 1 && choice != 2) { puts("Choose 1, 2 or 0"); continue; }
        puts("Temperature?");
        if (scanf("%lf", &value) != 1) return 1;
        printf("%.2f\n", choice == 1 ? to_f(value) : to_c(value));
    }
    return 0;
}

Compile and run the capstone

cc converter.c -o converter
./converter

Common mistakes

  • Do not omit & for numeric scanf destinations or use %f where scanf needs %lf.
  • Array bounds are your responsibility; C does not stop every out-of-range access.
  • 5/2 is2. Do not silently expect2.5.
  • Compile one example at a time and use Terminal for keyboard input. Website/host checks are not the owner’s TCC device pass.

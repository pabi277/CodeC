Get the CodeC APK.

CodeC is distributed from GitHub only — there is no Play Store or F-Droid listing. Three ways to get it, in order of freshness.

Go to Releases Already installed? Start here

Three ways to get the APK

1. Latest build (GitHub Actions)

Every green Build APK run produces a fresh APK. Open the Actions tab → the latest green Build APK run → Artifacts → download CodeC-IDE. That zip contains the APK.

2. A release

Open the Releases page and download the APK attached to the release. Releases are tagged builds — handy when you want a version you can come back to.

3. In the app (updates)

Already have CodeC? Update without leaving it: Settings → Install APK from GitHub downloads the latest release APK and opens the installer for you.

First install: allow the installer once

Android installs apps from outside a store only after you allow it for the app you downloaded with (your browser, for example). On first install: open the downloaded APK → Android asks to allow Install unknown apps for your browser → allow it once → continue the install. You only do this once per browser.

Will it work on my device?

DeviceExperience
arm64 phone / tabletBest. The built-in TCC compiler ships for arm64-v8a — every engine is available.
x86_64 emulatorGood. The built-in TCC covers x86_64 automatically. The bundled Clang module is arm64-only, so it can't run there — TCC picks up the slack.
32-bit deviceTermux engine recommended. The built-in compiler can't run on 32-bit; switch to the Termux engine in Settings (below).

Optional: the Termux engine

CodeC works fully standalone — Termux is never required. But you can add it as a fourth compiler engine for full C11/C17 via Clang or as a fallback if a toolchain is ever blocked on your device. You need Termux 0.109+ from F-Droid or GitHub (the Play Store version is outdated and does not support this). Then, in Termux:

echo "allow-external-apps=true" >> ~/.termux/termux.properties
termux-reload-settings
pkg update && pkg install clang

…and grant CodeC the “Run commands in Termux environment” permission (Android Settings → Apps → CodeC IDE → Permissions → Additional permissions). Verify the whole chain with Settings → Compiler Engine → CHECK BRIDGE. The engines compared: Engines.

$ first hour

Your first hour with CodeC.

Assumes the app is installed (get the APK here). Everything below happens on your phone, offline — you'll compile C, drive a real terminal, install a package, and preview a web page.

Step 1 — Your first compile (one tap)

Create a new file, name it hello.c, and type the program every C programmer starts with:

#include <stdio.h>

int main(void) {
    printf("Hello, CodeC!\n");
    return 0;
}

Tap RUN ▶. The output appears right under the editor. What just happened: CodeC's built-in TCC compiler — embedded in the APK — compiled your program to a static executable instantly and offline. No Termux, no downloads, no setup.

Step 2 — The terminal loop

The editor's RUN button is the quick path; the terminal is the craft. Open the Term tab (or tap the terminal icon in the editor toolbar) — a real VT/ANSI terminal starts. Type one command per line, Enter after each:

cc hello.c -o a.out
./a.out

cc is the built-in TCC. The ./ is not decoration — the current directory is not on PATH, so ./a.out is how you say “the file I just built, right here”. Projects live in app-private storage, which is exactly why ./a.out is executable.

Step 3 — Programs that read input

Programs that wait for you — scanf, getchar — must run in Term, not the RUN button (RUN has no keyboard into the process). Try this variant:

#include <stdio.h>

int main(void) {
    char name[64];
    printf("Your name: ");
    scanf("%63s", name);
    printf("Hello, %s!\n", name);
    return 0;
}

Compile with cc hello.c -o a.out, then run ./a.out in Term and type your name when it asks. (If you RUN it from the editor instead, it hits the 10 second execution cap — that's the app waiting for input, not a bug.)

Step 4 — Install a package (1 tap)

Open the Packages tab: a visual package hub with live status badges (INSTALLED ✓ / AVAILABLE). Find nano (a terminal text editor) or ripgrep, tap INSTALL, watch the badge flip, then tap RUN to start it right in the terminal. There are 25+ signed packages — git, python, clang, make, tmux and more. The full tour: Packages →

Step 5 — Preview a web page

Create an index.html and tap RUN ▶ — on an HTML file, RUN is the preview. The page is served by a local loopback server over your whole project folder, so relative CSS/JS, fetch("data.json") and ES modules just work. Edit → save → the preview live-reloads; console output shows under the page.

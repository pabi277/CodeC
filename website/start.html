BEFORE YOUR FIRST FILE

An introduction, then a place to play.

A fresh install starts with a three-step introduction. You can skip the educational pages; the privacy acknowledgement still needs to be read and accepted. That acknowledgement does not grant Android permissions or start a network request.

Next comes the editable, offline CodeC Arcade project: an index with Snake, Block Party and Tic-Tac-Toe. Play, open the files and experiment. It is seeded once, not overwritten on every launch; deleting it is respected. Returning sessions restore the last file instead. You can replay the introduction from Settings → About.

Start small. Add Linux later.

HTML preview and built-in C on arm64-v8a / x86_64 do not require downloading the Linux userland. Open Terminal when you want the optional Linux setup for the fuller shell, package tools and languages. Setup is opt-in and does not lock you out of the other tabs.

For this route, try steps 1 and 5 first if you want to stay offline. Continue with steps 2–4 after the needed environment is ready. Check your device’s compiler limits if C cannot run.

01 / WRITE SOMETHING THAT RUNS

Say hello in C.

  1. Open Projects → + → New Project. Name it FirstSteps, leave the project type at Auto (detect) and create it. Auto starts empty; you don’t need to choose a compiler.
  2. Creation opens the project in the Editor. Open its file drawer and choose New file. Create hello.c in the project root and open it.
  3. Enter the complete code below. CodeC autosaves after a short pause (about two seconds); let the save finish.
  4. With hello.c open, tap RUN ▶. CodeC uses the active source file. Read the output panel.

hello.c · complete example

#include <stdio.h>

int main(void) {
    puts("Hello, CodeC!");
    return 0;
}

Expected program output

Hello, CodeC!

Try a change: replace the greeting, wait for autosave and tap RUN again. You have just edited, compiled and executed a program.

If the first run does not work

Check the .c filename, quotes and semicolon. Keep hello.c open, not a header or text file. If the output reports a blocked toolchain or CPU mismatch, follow its guidance and the optional Termux fallback instructions. There is no engine picker to hunt for.

02 / SEE THE TWO STEPS

Compile. Then run.

The terminal makes the two operations visible: cc turns source into a program; ./a.out executes that program. For the full Linux terminal experience, open Terminal and choose its optional setup if prompted. The initial download needs internet; C and HTML above are not gated on it.

Return to your project’s file tree in Projects. Open the ⋮ menu for hello.c → Run in Terminal. This hands the file to Terminal in the right folder and runs it. Once that finishes, reproduce the build yourself:

CodeC Terminal · enter one command per line

cc hello.c -o a.out
./a.out

Expected program output

Hello, CodeC!
  • cc is CodeC’s compiler front end, not a promise of desktop GCC compatibility.
  • Keep the output option at the end: -o a.out.
  • The ./ is intentional. It runs a file in the current folder; do not add . to PATH.
  • If the terminal says it cannot find hello.c, use its file-tree Run in Terminal action again to return to the correct project folder.

03 / MAKE IT A CONVERSATION

Give your program a number.

Create double.c beside hello.c using the Editor’s file drawer. Use Terminal for this interactive exercise so you can type into the running program. You do not need to replace the first file.

double.c · complete example

#include <stdio.h>

int main(void) {
    int number;
    puts("Type a small whole number:");
    if (scanf("%d", &number) != 1) {
        puts("That was not a number.");
        return 1;
    }
    printf("Twice that is %d\n", number * 2);
    return 0;
}

Wait for the save, then return to the Terminal session in the same project folder. Compile this file only and run it. When prompted, type 21 and press Enter:

cc double.c -o a.out
./a.out

Expected interaction · 21 is what you type

Type a small whole number:
21
Twice that is 42

A program waiting at scanf is waiting for input, not necessarily frozen. Finish the line with Enter. Compile each example separately: both files define their own main.

04 / ADD ONE TOOL

Install a package when you need it.

After the optional Linux setup, open Packages. Find Python and tap INSTALL. The list distinguishes AVAILABLE from INSTALLED; packages with a launch action offer RUN after installation.

You can also install from CodeC’s terminal:

CodeC Terminal · Python package

pkg install python
python3 --version

Expected result: installation completes, then a line beginning Python 3. reports the installed version. The exact version can change. Downloads need internet; once installed, local Python programs do not inherently need a connection.

Use CodeC’s package environment

Do not add official Termux repositories to CodeC. They are different environments. If setup or an install fails, use the app’s status/heal/repair guidance and the troubleshooting guide rather than mixing package sources.

05 / SEE YOUR IDEAS IN A BROWSER

Make a tiny web page.

In Projects → + → New Project, create FirstWeb with the Static Web template. It supplies index.html. Open that file and replace it with this complete page:

index.html · complete example

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1">
  <title>Made on my phone</title>
</head>
<body>
  <h1>Hello from CodeC!</h1>
  <p>My first local web page.</p>
</body>
</html>

Wait for autosave and tap RUN ▶. For HTML, RUN opens Web Preview, not a C compiler. Expect the heading “Hello from CodeC!” and the paragraph below it.

The local server serves the project folder, so relative CSS, JavaScript and image paths work. Save an edit to see it in the live preview; reload if needed. No Linux download is needed for this static HTML example.

Optional: show the page on another device over Wi-Fi

In the preview/server controls, turn on LAN sharing. The share panel separates On this phone from Other devices. Use the Other devices URL or its QR code on a device on the same Wi-Fi network.

The phone-local loopback address will not open your phone’s server from another device. Use the displayed LAN address, keep CodeC’s server running and make sure your Wi-Fi allows devices to talk to each other.

Share only a non-sensitive project: LAN mode exposes the project’s served files to reachable network peers. It is not a public hosting service. Turn sharing off when finished; without it, the preview is local to the phone.

YOUR POCKET MAP

Five tabs. One workspace.

01 Projects
Create, clone or import a ZIP. Tap a file for that file; use a project’s ⋮ → Open in editor for the whole workspace. Export backups here too.
02 Editor
Write with syntax highlighting and autosave, use the file drawer and tap RUN for the active source or HTML page.
03 Terminal
Enter commands and interact with running programs. This is also where you opt into the Linux environment.
04 Packages
Browse available tools, install what you need and see what is already installed.
05 Settings
Adjust the app. About contains release/update information and the introduction replay. AI configuration is optional, not required for this guide.

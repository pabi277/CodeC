Python in CodeC

Install Python when you need it, then write a utility with a clear input and result.

What you will learn

  • Distinguish the python package from the python3 executable.
  • Use the REPL, save a script and read a text file safely.

Before you begin

Optional Linux setup, internet for installation, Chapters 3/5/6. No AI account or external Python library needed.

Add the interpreter

Open Packages, find Python3 and tap INSTALL, or use the terminal. The package is python; the executable is python3. Confirm the prompt if asked.

Install and verify

pkg install python
python3 --version

Expected: a Python3 version line. A syntax-highlighting grammar does not install a runtime. If pip work is needed later, python-pip is a separate configured root; this chapter uses only the standard library.

Ask the interpreter a small question

Start the REPL

python3

Type these at the Python prompt

2 + 3
print("Hello, CodeC")
exit()

Expected:5, then the greeting, then the shell prompt returns. The >>> prompt is not part of source code. Interactive input belongs in Terminal.

Save a real script

hello.py

name = "CodeC"
for number in range(1, 4):
    print(number, "Hello,", name)

Run a saved file

python3 hello.py

Expected output

1 Hello, CodeC
2 Hello, CodeC
3 Hello, CodeC

Indentation creates the loop body. Use consistent spaces and do not mix copied prompt symbols into the file. RUN on the active Python file can use the installed runtime too.

Count a text file

Save count.py below. It requires exactly one filename, reports a readable error instead of a traceback for common file failures, and never edits the input.

count.py

import sys
from pathlib import Path

if len(sys.argv) != 2:
    print("Usage: python3 count.py FILE", file=sys.stderr)
    raise SystemExit(2)
try:
    text = Path(sys.argv[1]).read_text(encoding="utf-8")
except (OSError, UnicodeError) as error:
    print("Cannot read:", error, file=sys.stderr)
    raise SystemExit(1)
print("lines:", len(text.splitlines()))
print("words:", len(text.split()))

sample.txt

one two
three

Run the utility

python3 count.py sample.txt

Expected output

lines: 2
words: 3

splitlines counts text lines, while split counts whitespace-separated words. The filename is relative to the terminal’s working directory; use pwd/ls if it cannot be found.

Keep dependencies deliberate

This example needs no pip package, network service or hard-coded Android storage path. If a later project adds a dependency, document and review it rather than run a random install command. Do not expect Tkinter or a desktop display environment from the curated mobile runtime.

Try it yourself

  1. Add a third line “four five” to sample.txt. Expected:3 lines and5 words.
  2. Run the utility without a filename. Expected: usage text and exit2.
  3. Pass a nonexistent file. Expected: a readable error and exit1, with existing files unchanged.

Common mistakes

  • python is the package name here; python3 is the command used in these lessons.
  • A missing file often means a wrong working directory, not a broken interpreter.
  • An installed runtime does not require internet for every local script; installs and network operations do.

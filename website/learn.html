Begin with what you have

You need a supported Android phone, CodeC and curiosity—not a computer or an AI subscription. First install the signed GitHub APK using Install. Built-in C on arm64-v8a/x86_64 and static HTML work without the optional Linux download. Later shell, package and Python chapters tell you when setup and internet are needed.

The current first run opens an editable Arcade project after a skippable introduction and privacy acknowledgement. It is a starting point, not a mandatory tour or a requirement to finish a game.

How to use the course

  1. Read the goals and prerequisites. Create a disposable practice project for experiments rather than changing important work.
  2. Type each complete file into the Editor, wait for autosave and run the commands one line at a time. Code blocks show source, commands or expected output—not an executable website.
  3. Compare the result with the expected text. Device paths, versions, addresses and sensor values can vary where stated.
  4. Try the exercises. Keep a backup before destructive changes; do not put credentials into source files. Use the common-mistakes section before reinstalling anything.

Every essential example is included locally. Repository links are optional evidence, not required reading to finish an exercise. Chapter links and all site assets work from an extracted copy.

Review status and device gates

Written is not the same as device-accepted

The full 29-page website is a local review edition, not a public deployment. Chapter 8 needs owner transcripts for input, loops, pointers and its converter. Chapter 16 projects P1 (calculator) and P5 (automation) also need real-device results. Expected outputs are teaching targets, not fabricated test passes.

Website/browser checks cannot verify Android permissions, TCC execution or spoken output. The final two chapters teach optional AI with your own key; they do not promise deterministic model answers or widen permissions.

Educational use and scope

Read and test every program before relying on it. Examples are small teaching programs, not hardened production software. Package availability, Android behavior and provider terms can change. This edition describes app-v1.3.18 and source snapshot 8467ff8.

Course license decision is pending (O7). No new course-content license is invented by this review edition; consult the repository’s existing notices and seek clarification before redistribution. App screenshot approval and a custom domain also remain owner decisions.

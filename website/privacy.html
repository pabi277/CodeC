Two claims—and an important correction

No telemetry: CodeC has no analytics, ad, tracking or automatic crash-upload SDK. A local crash log is not a remote report; it leaves when you choose to share it. This website also uses no analytics, cookies, embedded services or external assets.

Nothing leaves unless you start it: Git/package/update operations and AI requests are connected features you invoke. That is not the same as saying code can never leave the device.

With ONE approval it can read your files

An optional Android all-files grant allows broader shared-storage reads. Understand it before approving and revoke it in Android Settings if no longer needed. Private projects work without granting blanket shared-storage access. This is a permission disclosure—not instructions to use the Open Folder feature, which was removed. Current project entry points are New, Clone and Import ZIP.

Acknowledgement is not a permission grant

A fresh install’s introduction ends in a privacy acknowledgement. Educational pages can be skipped; normal entry still needs acknowledgement. It grants no Android permission and starts no network request. Crash-recovery safe mode bypasses onboarding/sample seeding so recovery is not blocked.

Where AI data goes

Send approves a disclosed task, including bounded read-only follow-ups that may transmit more admitted file text without a fresh tap for each read. Read the expandable timeline to inspect exact results. Continue creates a fresh preview and needs Send; a pre-text rate failure can retry once with a visible, cancelable countdown.

Two separate approval doors

  • Apply / Reject changes: the model proposes a diff; only your Apply writes through the dedicated applier. There is no write tool.
  • Run / Skip: request_run creates a card; only your Run enters the normal RUN pipeline. Bounded real output/exit can return to the provider. There is no exec tool.
  • Undo AI changes: the last applied task has a journal limited to five files / 256 KB. It can refuse after conflicting manual edits; it does not undo commands, network traffic, packages or Git operations.

Gemini requests go to generativelanguage.googleapis.com with your header key; NVIDIA requests go to integrate.api.nvidia.com/v1/chat/completions with a Bearer header. No CodeC relay or proxy sits between. NVIDIA is manual dev/test only, under separate terms.

Gemini stateless/store:false handling is not a provider zero-retention guarantee; free-tier terms may allow product improvement or human review. NVIDIA trial terms also allow retention/security exceptions, and CodeC does not send it an unsupported Google store flag. Do not send confidential information or real secrets.

Test connection sends a fixed one-word request, no project code. One pre-text rate retry is visible/cancelable; partial output is not silently replayed. Continue and provider/model changes require a fresh preview/Send. Read follow-ups inside the approved task can carry admitted text without a separate confirmation for every read.

Stored data is not all the same

Raw questions, answers, tool results and drawer titles are session-only. D6 keeps raw chat out of files, logs and backups. The drawer holds up to 20 conversations per project; follow-ups carry up to 8 turns. App death clears the session.

A separate, narrowly bounded task-memory cache may persist admitted non-secret file snapshots and structured findings/decisions/plan under no_backup/ai/task/: at most five files, 160 KiB of file content and 256 KiB total. It is not a transcript. Last-task undo preimages are another bounded store under no_backup/ai/undo/. Project deletion or deleting a provider key clears those task/undo stores.

Keys use AES-256-GCM Keystore encryption in no_backup/ai; model/terms/layout preferences are settings, not chat. Decryption failure removes the affected key and asks for it again. Support export scrubs stored key literals and common key shapes, but you must still inspect screenshots/logs before sharing.

Backups and crash reports

Auto Backup’s include-list carries CodeC/projects only. Userland, temporary outputs, settings, GitHub tokens and no_backup AI stores are excluded. Export all projects is the explicit source-project ZIP route; save it outside private storage before uninstalling.

A crash log contains a Java stack trace and device/build details. It stays local until you choose a Copy/Share/Send-report action. Inspect it and remove sensitive user content before posting. A new install is not a restore of credentials or the Linux environment.

How to inspect the claims

The named source files are evidence, not opaque assurances: StorageAccessPolicy; AiKeyStore; AiProjectFiles/AiProjectReader/AiToolRunner; AiEditApplier; AiTaskMemoryStore; AiChatSession/AiChatHistory; AiSecretScan; backup_rules.xml and data_extraction_rules.xml.

Install only what you need

  1. Open Terminal and choose the optional Linux setup if needed. Initial setup needs internet; C and static HTML do not depend on it.
  2. Open Packages, find a tool and tap INSTALL. AVAILABLE and INSTALLED badges reflect the app’s binary checks. A supported launch action changes to RUN.
  3. Wait for the operation to finish; installation does not lock other navigation. Do not start competing package mutations. Read the failure rather than repeatedly tapping install.

Example · install Python

pkg install python
python3 --version

Confirm the package prompt if asked. Expected: a Python 3 version line; the exact version is not pinned by this guide.

What “signed” means here

The bootstrap is verified, staged and installed atomically. The package frontend checks metadata and uses OpenPGP signed-by= trust, failing closed when verification fails. Keep the built-in source/key configuration intact; never use trusted=yes to bypass a warning.

CodeC uses its own com.codeci.ide prefix and source-built packages. Official com.termux binaries and repository entries do not belong in it. Do not overwrite cc or replace the real Bash executable with a wrapper.

Useful actions, in a safe order

Package and environment actions
ActionUse
pkg statusInspect the environment before changing it
pkg updateRefresh signed package metadata; needs network
pkg upgradeReview available upgrades; confirm deliberately
pkg heal / pkg repairUse the app’s recovery guidance after interrupted/broken setup
codec-setup-storageOptional shared-storage links and permission; not required for private projects

Read prompts before confirming; export important source projects before a major repair or fresh install. Repository availability, downloads and Android restrictions can fail independently.

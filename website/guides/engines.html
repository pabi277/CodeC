How Auto works

CodeC tries built-in TCC first, the optional Clang module when available, then a compatible Termux compiler when Android blocks the toolchain. These are conceptual engines, not buttons to select. The engine picker and old Termux Settings card are gone.

Compiler paths
PathStrengthLimit
Built-in TCCSmall, offline C; no userland downloadBundled for arm64-v8a and x86_64 only
Optional Clang moduleAdditional compiler diagnostics and language supportModule is arm64-only; download needed
Termux fallbackCompatible external compiler environmentSeparate app, setup and permission; not guaranteed on every device

Start with ordinary C

The course starts with conservative C examples. TCC covers ANSI C and much of C99; it is not a guarantee that every C11/C17 feature or desktop library works. cc is CodeC’s TCC front end, not a shell shim to overwrite.

Terminal · one command per line

cc hello.c -o a.out
./a.out

Keep -o last. Use ./ instead of adding the current directory to PATH. For keyboard input, use Terminal. See your first C program.

Read the failure before changing anything

  • Permission denied: Android execution policy or a noexec location may block the compiler. Retry in an app-private project and read Output’s remediation.
  • Exec format error: executable and CPU architecture disagree; reinstalling a random compiler is not a fix.
  • 32-bit device: no bundled TCC; an arm64 Clang module cannot repair that. The beta also records older-tablet startup problems.
  • x86_64: bundled TCC is available, but the arm64 module is not an x86 compiler.

Set up fallback only when needed

The Output Panel prints setup guidance when a build needs it. Install compatible Termux 0.109+ from the sources linked in Install. Run these inside Termux itself, not CodeC:

Termux-only commands

echo "allow-external-apps=true" >> ~/.termux/termux.properties
termux-reload-settings
pkg update && pkg install clang

Allow Android Settings → Apps → CodeC IDE → Permissions → Additional permissions → Run commands in Termux environment, then retry CodeC’s build. Labels may vary. No engine selection is required; never add Termux repositories to CodeC.

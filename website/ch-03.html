The CodeC Terminal

Learn a small command vocabulary, keep your bearings and give running programs input.

What you will learn

  • Navigate and change disposable files safely.
  • Distinguish command input from program input and use sessions.

Before you begin

A ready optional Linux environment. Create a disposable working folder; never practice deletion in important projects.

Know where the shell is

Open the middle Terminal tab or the Editor terminal icon. A file-tree Run in Terminal action can place the shell in a project; a new session can start in your home. Check rather than guess:

Locate the current folder

pwd
ls
printf '%s\n' "$PREFIX"

pwd prints your current directory. ls lists its entries. PREFIX names the installed-tool tree, not necessarily the current working directory. One command per line is the beginner habit; wait for the prompt or output before the next.

The commands you will reuse

Command vocabulary
CommandMeaningExample
pwd / lsShow location / entriespwd; then ls
cdChange directorycd demo; cd ..; cd
mkdir / touchCreate directory / empty filemkdir demo; touch a.txt
catPrint textcat a.txt
cp / mvCopy / move or renamecp a.txt copy.txt
rmDelete, without a desktop trash binrm copy.txt

The semicolons in this table separate examples; in the exercise below, enter one command per line. Paths and names are case-sensitive. Quote names containing spaces.

Build a harmless sandbox

Terminal · use a new demo folder

mkdir demo
cd demo
printf 'hello\n' > a.txt
cp a.txt b.txt
mkdir sub
mv b.txt sub/
ls
cat sub/b.txt

Expected cat result

hello

ls should include a.txt and sub; order/format may vary. The > operator writes a file and replaces prior content, so use a new filename for experiments. Avoid broad wildcard deletion.

A program has its own input

Compile this as ask.c, then run it in Terminal. After “Number?” appears, type7 and press Enter; do not type the next shell command into the running program.

ask.c

#include <stdio.h>
int main(void) {
    int n;
    puts("Number?");
    if (scanf("%d", &n) != 1) return 1;
    printf("You typed %d\n", n);
    return 0;
}

Compile and run

cc ask.c -o ask
./ask

Expected interaction

Number?
7
You typed 7

More than one terminal

The session switcher supports multiple sessions, with rename and close actions; the default manager cap is eight. Use a clear name for a long-running job so you do not type into the wrong session. Ctrl-C interrupts a foreground command where it handles that signal. ESC/TAB/CTRL/ALT/arrows help on a phone keyboard.

Closing a session or Android killing the process can end its work. A foreground service helps, but battery restrictions still matter. tmux organizes shell work; it cannot override the OS.

Try it yourself

  1. Inside demo, create a second subdirectory and move a copy into it. Verify with ls and cat.
  2. After the input program exits, run pwd. Expected: the shell now reads commands again.
  3. Clean up only the known disposable copies using explicit filenames; verify the original a.txt remains.

Common mistakes

  • rm has no normal trash recovery; inspect pwd before deleting.
  • An input prompt is not automatically a hang. Enter finishes the line.
  • Do not add . to PATH or confuse PREFIX with your working directory.

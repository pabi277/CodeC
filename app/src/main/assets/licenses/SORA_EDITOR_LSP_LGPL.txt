CodeC — NOTICE for io.github.rosemoe:editor-lsp
================================================

Phase 31 (2026-09-07): CodeC uses the `editor-lsp` module of the
sora-editor project (https://github.com/Rosemoe/sora-editor) as a BINARY
Gradle dependency from Maven Central, at the same pinned version as the
`editor` widget and the `language-textmate` module (0.24.6 — see
gradle/libs.versions.toml).

The module is consumed unmodified as a Java library; no sora source is
copied into the CodeC tree. It exposes the LSP client/wrapper classes
that CodeC's LspManager integrates against. The class shim pattern (a
LspManager provider interface so the integration stays host-testable) is
CodeC's own design, not a copy of any sora example code.

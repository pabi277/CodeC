CodeC — NOTICE for the TextMate grammars and themes (MIT)
==========================================================

Phase 29 (2026-09-05): the files under assets/textmate/grammars/ and
assets/textmate/themes/ are TextMate grammar/theme JSONs. Unless noted
below, they are UNMODIFIED copies of MIT-licensed files; CodeC
redistributes them inside the APK with attribution, which the MIT license
permits. File names were shortened (scope names inside the files are
untouched).

Themes (assets/textmate/themes/)
--------------------------------
vscode-dark-plus.json: derived from microsoft/vscode (MIT)
  extensions/theme-defaults/themes/dark_vs.json + dark_plus.json, flattened
  into one file (dark_vs "colors" + dark_plus "tokenColors"; JSONC comments
  and trailing commas removed so the file is strict JSON). The classic
  Dark+ editor chrome colors that vscode moved to workbench defaults
  (caret, line highlight, line numbers, selection) were restored.
  Copyright (c) Microsoft Corporation. MIT License.

monokai.json: derived from microsoft/vscode (MIT)
  extensions/theme-monokai/themes/monokai-color-theme.json, comments
  stripped to strict JSON.
  Copyright (c) Microsoft Corporation. MIT License.

dracula.json, github-dark.json: AUTHORED FOR CodeC (not copies).
  Written for Phase 29 using the Dracula (https://draculatheme.com) and
  GitHub dark palettes already shipped by CodeC since Phase 12/25, applied
  to the same token-scope structure as vscode-dark-plus.json. Released by CodeC
  under the MIT License.

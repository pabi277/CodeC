The owner's corrections, honoured: all 7 beats stay, the first project is chosen and named by the user (the arena becomes one option, not an imposition), and the visual language is modern and authentic. A · Authenticity: never draw what the app can show

The reference flow illustrates with emoji inside white circles. Emoji render differently on every OEM, and a waving hand teaches nothing about code. CodeC's hero art is always the product: the real first line of the file you are about to create, your own project name in the breadcrumb, the actual compiler output, the real file list. That is what "authentic" means here — and it is cheaper than illustration, because the assets already exist.

C · The laws that keep it honest

Non-negotiables

  • Skip ≡ today — "Skip setup" seeds the Arcade sample and writes nothing, so the flow can never be slower than the current build.
  • No profile is kept — one gate key plus the chosen project id; nothing is sent anywhere; documented in DATA_AND_PRIVACY.md.
  • Upgraders never see it — the flow lives inside the existing first-run gate; first_launch_complete = true means no re-onboarding.
  • Phase 64.2's line holds — the flow explains nothing about how to use the app: no tips, no arrows, no spotlights, no locks. Every screen ends in a settings write or a created project.
  • It is still a new first-run surface — so it needs the owner's explicit word and a phase number (97) before any code.

The modern/authentic checklist a reviewer can enforce

  • Hero art = product content (real code, real file names, real output, real chrome). No emoji, no stock, no abstract blobs.
  • One loud element per screen — the mint glow appears twice in seven screens (S1, S7).
  • Type contrast over type quantity: one display line per screen; captions in MUTED_TEXT.
  • Every control's effect is visible either instantly (S4/S5) or in the next screen (S2/S3).
  • Motion from CodecMotion only (300 ms emphasized steps, 380/0.8 selection spring), and everything snaps under reduced motion.
  • Haptics: existing tick moments only — selection, success. Never on skip, never on entry.
  • 48 dp targets, headings, live regions, and legible at 200 % font scale.
